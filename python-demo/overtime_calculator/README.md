# 加班时长统计工具

一个基于 Python + Streamlit 的加班时长统计工具，提供简洁的 Web 界面，支持加班记录管理、统计分析、数据导出等功能。

## 功能特点

✨ **核心功能**
- 📝 加班记录添加、编辑、删除
- ⏰ 自动计算加班时长
- 📊 可视化统计报表（饼图、柱状图、趋势图）
- 📈 多维度统计分析（按类型、项目、时间）
- 📥 数据导出为 Excel

🎯 **智能特性**
- 自动识别加班类型（工作日/周末/节假日）
- 支持跨天加班计算（如加班到凌晨）
- 智能时长计算（扣除休息时间）
- 项目维度统计
- 日期范围筛选

## 快速开始

### 1. 安装依赖

```bash
cd python-demo/overtime_calculator
pip install -r requirements.txt
```

### 2. 运行应用

```bash
echo "" | python3 -m streamlit run app.py
```

应用将自动在浏览器中打开，默认地址：http://localhost:8501

## 使用说明

### 添加加班记录

1. 点击侧边栏的 **"添加记录"**
2. 填写以下信息：
   - **日期**：选择加班日期
   - **开始时间**：加班开始时间
   - **结束时间**：加班结束时间
   - **项目名称**：可选，填写相关项目
   - **加班原因**：可选，简要说明原因
3. 系统自动计算加班时长并识别加班类型
4. 点击 **"提交"** 保存记录

### 查看和管理记录

1. 点击 **"记录管理"**
2. 查看所有加班记录列表
3. 使用筛选器按日期范围或项目筛选
4. 可以编辑或删除已有记录

### 统计分析

1. 点击 **"统计报表"**
2. 查看总览卡片：
   - 总加班时长和天数
   - 工作日/周末/节假日加班时长
3. 查看可视化图表：
   - 加班类型分布饼图
   - 各项目加班时长柱状图
   - 加班时长趋势折线图
4. 导出数据为 Excel 文件

## 数据存储

- 使用 SQLite 数据库存储数据
- 数据文件位置：`data/overtime.db`
- 自动创建目录和数据库

## 技术栈

- **Streamlit**: Web 界面框架
- **SQLite**: 数据存储
- **Pandas**: 数据处理
- **Plotly**: 数据可视化
- **OpenPyXL**: Excel 导出

## 注意事项

1. **跨天加班**：如果结束时间早于开始时间，系统会自动识别为跨天加班（如 18:00 - 次日 02:00）

2. **最小加班时长**：单次加班至少 15 分钟

3. **最大加班时长**：单次加班不能超过 24 小时

4. **节假日识别**：当前版本暂不支持法定节假日自动识别，节假日需手动调整类型

## 常见问题

**Q: 如何备份数据？**
A: 直接复制 `data/overtime.db` 文件即可。

**Q: 如何修改已有记录？**
A: 在"记录管理"页面找到对应记录，点击"编辑"按钮。

**Q: 支持多用户吗？**
A: 当前版本为单用户版本，所有数据存储在本地数据库。
